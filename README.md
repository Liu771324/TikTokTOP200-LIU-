# Script All 电商工具库

这个仓库聚合面向抖音电商工作的本地脚本和小工具。每个工具保留自己的业务流程、运行方式和数据目录；总仓负责管理项目、说明和版本，不要求把工具改造成同一个应用。

## 工具目录

| 工具 | 目录 | 用途 |
| --- | --- | --- |
| 商机中心 | `商机中心/` | 商机数据采集与选品报告（Node.js 版） |
| 商机中心 Python 版 | `商机中心--Python/` | 独立的商机采集实现 |
| 搜索词 | `Search term/` | 商机词与罗盘搜索词采集 |
| 商品榜单 | `Tiktok TOP200/` | 抖音电商罗盘商品榜单采集 |
| 短视频榜 | `Tiktok video/` | 短视频榜采集、视频和文案整理 |
| 视频下载器 | `抖音视频下载器（免 Python 版）/` | 抖音公开视频下载工具源码与打包说明 |
| 商品标题工作台 | `Product Title/` | 商品标题本地工作台 |
| 成本助手 | `Cost Accounting(成本价）/` | 聚水潭成本价同步和抖店只读成本辅助 |
| 净含量提取 | `Net weight of the product（净含量）/` | 从商品资料中提取最小净含量 |

具体启动要求、使用边界和数据位置以各工具目录中的说明为准。当前仓库没有统一安装器；工具按各自说明独立启动。

## 仓库约定

- `main` 是工具库集成分支，收录已经纳入工具库的项目。
- 按单个工具创建开发分支，分支名使用 `tool/<工具标识>`；改动只涉及对应工具目录和必要的总仓目录说明。
- 新工具先放在独立目录，补上用途、运行要求和启动说明。准备好后通过 Pull Request 合并到 `main`。
- 保持工具之间的依赖和数据目录独立，不因总仓整合而强行统一业务流程。
- 用户表格、采集结果、日志、缓存、虚拟环境和打包产物不提交到源码仓库。大体积安装包在需求明确后再用 GitHub Releases 或下载服务分发。

分支与目录规则见 [`docs/REPOSITORY_STRUCTURE.md`](docs/REPOSITORY_STRUCTURE.md)。

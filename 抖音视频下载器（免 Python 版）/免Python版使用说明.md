# 抖音视频下载器（免 Python 版）

## 使用条件

- Windows 10 或 Windows 11，64 位系统。
- 电脑已安装 Microsoft Edge（Windows 通常自带）。
- 能正常访问公开的抖音视频页面。

## 使用方法

1. 双击 `DouyinVideoDownloader.exe`。
2. 在 1~5 号框各粘贴一个抖音链接或完整分享文案（最多 5 个，留空自动跳过），程序会按顺序逐个下载。
3. 选择保存目录。
4. 点击“开始下载”。

目标电脑不需要安装 Python、Playwright、Requests 或 FFmpeg；发布版会自带音视频合并组件。

## 当前范围

- 支持公开可播放的抖音视频链接与短链接，可一次提交多个并按顺序批量下载，单个失败不影响其余。
- 保存页面实际播放的 MP4 视频。
- 不登录账号、不处理验证码、不绕过访问限制。
- 当前版本不做去水印处理。

## 常见问题

- 提示找不到 Edge：安装或更新 Microsoft Edge 后重试。
- 提示验证码或视频受限：请先在浏览器确认该视频能够公开播放。
- 提示音视频合并失败：确认使用的是最新发布版，不要只复制旧的 EXE。
- Windows 首次运行可能显示安全提醒，这是未进行商业代码签名导致的；请仅分发你自己构建或确认来源的文件。

## 重新构建

开发电脑安装依赖后，在 PowerShell 中运行：

```powershell
./build_exe.ps1
```

输出文件位于 `dist/DouyinVideoDownloader.exe`。

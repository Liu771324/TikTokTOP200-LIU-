# 电商工具箱使用说明

## 安装与首次打开

1. 运行 Windows 安装程序，按向导安装，然后打开“电商工具箱”。
2. 选择要使用的工具，点击右上角“打开平台 / 登录”。
3. 在工具箱打开的专用 Edge 中完成平台登录，再回到工具箱。

商机中心使用抖店账号；商品 TOP200、自动短视频和罗盘本页视频读取使用抖音电商罗盘。人工视频工作台另有“打开抖音”入口。登录和验证码需要本人完成。首次使用需要联网，并安装 Microsoft Edge；缺少 WebView2 时，安装程序会引导安装。

采集结果由工具箱管理，不需要填写程序目录或文件路径。需要带走结果时，点击“导出”，在系统对话框中选择保存位置。

## 五个工具

### 商品标题工作台

1. 点击右上角“打开平台 / 登录”登录抖店，工作台内“打开小猪 / 登录”完成小猪登录。
2. 点击“选择 .xls / .xlsx 表格”，在系统窗口选文件，不需要改文件名或放进程序目录。表内需要 `Sheet1`，A1 为“原标题”、B1 为“新标题”；原标题留空沿用上一组，新标题留空跳过。标题正文不会自动缩短或改写，公式不接受。
3. “读取店铺和商品状态”，勾选本次店铺和状态；店铺默认不选。点击“预览商品修改”，等待只读查询结束。
4. 核对具体商品 ID、店铺、修改前标题、目标标题和表格行号。按平台查询顺序分配新标题，多余商品保留，多余新标题不使用；多个原标题命中同一商品会要求调整查询词。
5. 预览有效 10 分钟；更换表格、店铺或状态后须重新预览。点击“确认修改商品标题”并在确认窗口确认后才提交。
6. 在任务中心查看结果或停止。停止不撤回已成功保存的标题，当前已提交商品会先核对，通常最多约一分钟。结果不确定时显示“待核对”，先回平台确认，再决定是否创建新任务。标题任务不自动继续、重试或在重启后自动执行。
7. 可导出完整 JSON 和失败商品 Excel；商品、店铺 ID 在 Excel 中作为文本保存。原表格和独立标题工具保持不变。

本轮标题的真实平台保存留待用户验收；隔离样本通过不代表所有店铺和页面变化均已覆盖。

### 商机中心

点击“读取平台条件”，搜索并勾选官方类目，填写最低/最高成交金额后创建任务。商机中心现采用 Python API 采集，支持一级至三级类目；选择三级时包含它的下属类目。金额单位为元，只有整个成交档位包含在设置区间内才采集。“仅看近30天增长”使用平台近30天环比字段，缺失或异常会单独记录。

任务中心可暂停、继续、停止或重试失败项。暂停确认后停止发新请求；停止保留检查点和 Excel、JSON、Markdown 部分报告。继续从已提交进度恢复；来源数据变化导致不能安全合并时，会明确提示新建任务。检查商品ID、指标绑定、金额与档位、页内/跨页排序、重复页及覆盖范围，未完成或有异常不会标为完整。

结果中的“今日环比”来自平台近1天指标；“昨日（反推）”使用今日精确金额与环比计算档位，报告会说明计算来源。旧版商机任务的结果和文件仍可查看、导出；旧检查点不能用于新API引擎，请按原条件新建任务。

### 商品 TOP200

选择类目、榜单和品牌条件后开始采集。每个类目与榜单组合独立记录进度。停止后保留已经保存的进度；继续时，未完成的组合可能重新采集，以免混合两次榜单数据。

### 自动短视频

选择类目、品牌、周期及趋势条件后开始。符合条件的商品最多保存 4 条新视频；内容重复的视频可能引用已有文件。任务详情会显示视频、文案、重复及失败情况。

实时榜单会变化。若继续时商品或视频身份已改变，工具箱会提示重新读取或新建任务，避免把别的商品视频归档到原任务。

### 人工视频工作台

1. 点击工作台里的“打开罗盘”或“打开抖音”，在专用Edge中浏览需要的视频；也可以粘贴公开分享链接后“添加到待选列表”。
2. 点击“读取当前页”，选择对应的浏览器标签。罗盘读取当前短视频榜已识别的视频卡片，不按首次上榜过滤；抖音读取详情、作者主页、搜索或推荐中已加载且可识别的视频。手动翻页或浏览新视频后可再次读取。
3. 待选视频按商品或作者分组，显示封面、标题、来源、序号和读取时间。可按标题、商品或作者筛选；“选择本页”只勾选当前页，“清空选择”清除所有页的选择，“已选”显示累计数量，单次最多200条。
4. 有公开链接时可直接“复制链接”。罗盘没有公开链接时，先点击单条“提取链接”或“提取所选链接”，等待完成后复制播放地址。较多条目会分批排队，提取时会正常打开平台播放器。播放地址可能过期，重启软件后需重新提取；它不等于永久分享链接。
5. 单条用“下载这条”，批量勾选后用“下载所选”。在任务中心查看结果并导出。视频标题尚未读到时显示明确占位，封面失效可重新读取；复制标题不会把“标题未读取”当作真实标题。

提取或下载期间请保持原来源页面可用。翻页、切换筛选、商品或目标卡片变化，以及登录失效时，按提示重新读取。此前旧记录没有封面和商品信息的，可重新读取对应页面补充；旧记录不会自动删除。页面没有可识别视频时，可打开具体视频详情，或粘贴该视频公开分享链接。

## 任务与结果

- 在“任务中心”点击“查看”打开任务详情；右上角“×”或 Esc 可关闭，滚动后关闭按钮仍保持可见。
- 停止会保留已登记的结果。继续与重试不会主动删除成功文件；页面身份变化时按提示新建任务。
- 视频导出为视频与同名文案文本，按任务和商品归类；商机报告可导出 Excel、JSON 和 Markdown。导出不会移除内部结果。
- 同名视频导出会自动避让；单份报告使用系统保存对话框确认保存位置。
- 登录失效或需要验证码时，回到专用 Edge 完成处理，再按任务提示继续。

## 存储、退出与更新

在“存储管理”查看占用、清理缓存或删除任务。删除前会显示预计释放空间；被其他任务引用的视频会保留。不要直接删除工具箱内部文件。

### 更改数据保存位置

1. 在“存储管理”的“数据保存位置”查看当前目录和磁盘剩余空间。
2. 先结束运行或暂停的任务，等待页面读取完成，再点击“更改数据位置”，在系统窗口选择文件夹。工具箱会使用所选文件夹下的 `ScriptAllToolbox` 数据目录，无需输入路径。
3. 完成选择后使用“退出”结束软件，再次打开时完成数据复制与校验迁移。迁移完成前当前页面仍显示原位置与待迁移位置。
4. 迁移成功后回到“存储管理”，确认新位置可用，再点击“清理旧位置”回收原目录占用。

关闭主窗口后，工具箱会留在托盘。需要结束运行时，使用界面或托盘中的“退出”。安装更新前也应先退出。卸载程序保留任务、结果和登录资料；需要删除数据时先在工具箱中处理。

## 当前验收范围

0.1.4用户抽样后确认现有功能无问题。0.1.5的Python商机引擎已在隔离任务库使用真实受管页面核对类目、暂停、停止、部分报告及检查点恢复：首次停止9条，恢复至15条，未发现重复商品或失败；这不代表全类目、长任务和干净Windows机器均已验证。技术与交付记录见[重组及Python接入记录](../docs/TOOLBOX_REORGANIZATION_PYTHON_BUSINESS.md)，此前人工工作台范围见[记录](../docs/TOOLBOX_MANUAL_VIDEO_WORKSPACE.md)。


## 默认导出位置

在“存储管理 → 默认导出位置”点击“选择文件夹”，可以把常用下载文件夹设为默认位置。以后点击视频“导出”会直接保存到这里，按任务、商品归类并附带文案；重名文件自动避让。未设置时，视频导出仍每次选择文件夹。

报表和待选列表Excel仍弹出保存窗口，默认打开该文件夹，可以另选保存位置。内部视频继续在工具箱数据目录统一去重；下载完成不会自动向导出目录复制一份，也不会生成额外备份。更换默认导出位置不会搬动已经导出的文件。

# 短视频榜采集工具

本机网页工具会打开或连接 Microsoft Edge 调试会话，进入抖音电商罗盘的“短视频榜”读取筛选选项，按平台原始排名扫描最多前 200 名，并为符合条件的商品保存最多 4 条去重后的视频及对应文案。详细口径见 [需求与技术方案](./短视频榜采集工具-需求与技术方案.md)。

工具按页面顺序检查视频候选；遇到重复项会跳过并继续检查“+N”中的后续候选。候选不足时尽量保留至少 2 条不同视频，但不保证一定能找到两条。

## 启动

1. 安装 Node.js 20 或更高版本。
2. 在新电脑上首次配置时，可双击 [安装依赖.cmd](./安装依赖.cmd) 安装项目依赖；这一步需要网络连接。若依赖缺失，[启动采集.cmd](./启动采集.cmd) 也会自动安装。
3. 双击 [启动采集.cmd](./启动采集.cmd)。它会打开服务控制台和 <http://127.0.0.1:8080>，并自动打开调试版 Edge 的商机中心。已有 `9222` 调试会话时会直接复用。
4. 程序先经过商机中心，再进入罗盘“短视频榜”。若登录过期，请在商机中心手动登录并完成验证，再回到采集页点击“打开短视频榜”。
5. 点击“读取页面选项”，单选行业类目、品牌类型、榜单周期和趋势条件，再创建任务。关闭服务控制台可停止服务；也可以手动运行 `npm start`。

服务只监听 `127.0.0.1`。可通过环境变量 `PORT` 修改本机网页端口，通过 `CDP_URL` 修改 Edge 调试端点。程序按 TOP200 的方式使用独立 Edge 调试目录；如果自动检测不到 Edge，可将 `EDGE_PATH` 设为 `msedge.exe` 的完整路径。登录由用户手动完成，工具不保存密码或迁移 Cookie。

## 文件与续跑

- 每个商品开始下载前，程序先读取前 4 个视频卡片的文案。文件夹和视频文件的短名优先使用商品标题与这些文案全部共同包含的商品词，最多 24 个字符；“早餐”“营养”“食材”等泛场景词不作为商品主体。没有合适共同商品词时退回清理后的商品标题，优先保证名称中包含商品主体。目录冲突时追加商品标识短哈希。文件名使用短名和序号，如 `沙棘蜂蜜1.mp4`、`沙棘蜂蜜1.txt`；重名时再追加编号。
- 所有商品之间按视频文件 SHA-256 和抽样画面指纹判断视频是否重复。开头约 5 秒的抽样帧至少 80% 能对齐时视为重复；完整视频指纹中较长的一方至少有 12 个抽样帧时，若较短视频至少 80% 的帧能与另一条按顺序对齐也视为重复。文案相同不代表视频相同：不同视频会全部保留，空白归一且忽略大小写后完全一致的文案只保留一份 `.txt`。
- 每次任务开始会扫描 `视频/` 内已有的 MP4 并建立全局去重索引；发现文件哈希或画面重复时删除重复 MP4 和同名 `.txt`，保留先扫描到的视频。只有文案重复时，仅删除后出现的重复 `.txt`。若当次无法生成画面指纹，视频至少按文件哈希去重。
- 任务、检查点和索引保存在 `data/`，日志保存在 `logs/`。服务重启时，原来处于运行中的任务会改为“已停止”，检查点保留，可在页面续跑。
- 暂停和停止会等当前视频处理完成。续跑会检查榜单总数、每页条数和已记录的商品位置；这些发生变化时需新建任务。检查点记录本机输出路径，因此跨电脑或改变项目目录后续跑不保证能识别原有输出。
- 当文案读取失败但视频下载成功时，保留视频，记录日志，不创建空 `.txt`。
- 视频卡片若没有打开罗盘小播放器，而是新开抖音网页，工具会关闭这次新开的标签页并把该视频记为失败，继续处理后续卡片。

## FFmpeg

当页面返回独立音视频轨道，或单轨视频需要重新封装为 MP4 时，工具使用 FFmpeg 以 stream copy 方式合并/封装，不重新编码。项目不随附 FFmpeg 可执行文件。请从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)选择 Windows 构建并自行安装，然后把 `ffmpeg` 加入 `PATH`，或将 `FFMPEG_PATH` 设为 `ffmpeg.exe` 的完整路径。格式已是 MP4 的单轨视频不需要 FFmpeg。官方说明的许可条件见 [FFmpeg 法律页面](https://ffmpeg.org/legal.html)；本项目不重新分发 FFmpeg 二进制文件。

## 使用边界

工具只获取已登录页面正常播放流程提供的媒体地址，不处理验证码或访问限制，也不扩展为任意地址下载器。请仅保存有权使用的内容。

## 迁移

轻量迁移包只包含项目代码、网页资源、依赖清单、启动脚本和文档，不带 `node_modules`、任务数据、日志、视频或文案。目标电脑需安装 Node.js 20+，运行 `安装依赖.cmd` 下载依赖，再运行 `启动采集.cmd`。需在目标电脑的 Edge 中手动登录。

若要保留已采集文件，可另外复制 `视频/`。任务检查点里的输出路径是本机绝对路径，因此本轻量迁移包不支持把旧任务状态直接搬到不同电脑或不同项目目录续跑。

# 短视频榜采集工具

本机网页工具会打开或连接 Microsoft Edge 调试会话，进入抖音电商罗盘的“短视频榜”读取筛选选项，按平台原始排名扫描最多前 200 名，并将符合条件商品页面顺序最前的四条视频和对应文案保存到本目录的 `视频` 文件夹。详细口径见 [需求与技术方案](./短视频榜采集工具-需求与技术方案.md)。

## 启动

1. 安装 Node.js 20 或更高版本。
2. 在新电脑上首次配置时，可双击 [安装依赖.cmd](./安装依赖.cmd) 安装项目依赖；这一步需要网络连接。若依赖缺失，[启动采集.cmd](./启动采集.cmd) 也会自动安装。
3. 双击 [启动采集.cmd](./启动采集.cmd)。它会打开服务控制台和 <http://127.0.0.1:8080>，并自动打开调试版 Edge 的商机中心。已有 `9222` 调试会话时会直接复用。
4. 程序先经过商机中心，再进入罗盘“短视频榜”。若登录过期，请在商机中心手动登录并完成验证，再回到采集页点击“打开短视频榜”。
5. 点击“读取页面选项”，单选行业类目、品牌类型、榜单周期和趋势条件，再创建任务。关闭服务控制台可停止服务；也可以手动运行 `npm start`。

服务只监听 `127.0.0.1`。可通过环境变量 `PORT` 修改本机网页端口，通过 `CDP_URL` 修改 Edge 调试端点。程序按 TOP200 的方式使用独立 Edge 调试目录；如果自动检测不到 Edge，可将 `EDGE_PATH` 设为 `msedge.exe` 的完整路径。登录由用户手动完成，工具不保存密码或迁移 Cookie。

## 文件与续跑

- 视频与同名 `.txt` 文案保存在 `视频/短商品名/` 下；短商品名先去掉产地、促销和规格词，再从商品名与视频文案中提取共有商品词，例如 `沙棘蜂蜜/沙棘蜂蜜1.mp4` 与 `沙棘蜂蜜1.txt`。同一商品的所有视频共用一个短名。没有合适共有词时使用清理后的商品核心名；名称冲突时追加短编号。每条视频文案保留全文。
- 所有商品之间按 MP4 文件 SHA-256、文案完全一致和画面指纹去重。开头 5 秒主体画面相似度达到 80%，或较短视频的主体内容有 80% 能在另一条视频中按顺序对齐时，跳过重复视频及对应文案。候选视频重复时继续检查“+N”里的后续视频，最多保存 4 条不同视频，并尽量保证至少 2 条。
- 任务与检查点保存在 `data/`，日志保存在 `logs/`。重新启动服务后，曾在运行中的任务显示为“已停止”，可在页面续跑。
- 暂停和停止会等当前视频处理结束。续跑跳过已经落盘并记入检查点的视频；失败视频可重新处理，已有文件不会被覆盖。
- 当文案读取失败但视频下载成功时，保留视频，记录日志，不创建空 `.txt`。
- 视频卡片若没有打开罗盘小播放器，而是新开抖音网页，工具会关闭这次新开的标签页并把该视频记为失败，继续处理后续卡片。

## FFmpeg

页面返回独立音视频轨道时，工具使用 FFmpeg 无重新编码地合并为 MP4。项目不随附 FFmpeg 可执行文件。请从 [FFmpeg 官方下载页](https://ffmpeg.org/download.html)选择 Windows 构建并自行安装，然后把 `ffmpeg` 加入 `PATH`，或将 `FFMPEG_PATH` 设为 `ffmpeg.exe` 的完整路径。单轨 MP4 下载不需要 FFmpeg。官方说明的许可条件见 [FFmpeg 法律页面](https://ffmpeg.org/legal.html)；本项目不重新分发 FFmpeg 二进制文件。

## 使用边界

工具只获取已登录页面正常播放流程提供的媒体地址，不处理验证码或访问限制，也不扩展为任意地址下载器。请仅保存有权使用的内容。

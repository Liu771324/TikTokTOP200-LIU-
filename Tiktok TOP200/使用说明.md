# 抖音商品 TOP200 采集工具使用说明

> 开发、维护或继续接手项目，请阅读 [完整技术交接文档-TOP200采集系统.md](./完整技术交接文档-TOP200采集系统.md)。

## 一、第一次使用

1. 电脑需安装 Microsoft Edge 和 Node.js 20 或更高版本。
2. 双击 `安装依赖.bat`，等待出现“安装完成”。这一步每台电脑只需执行一次。
3. 双击 `启动采集.bat`，浏览器会自动打开本地采集页面。

本工具的网页、代码和数据都在当前文件夹内，不使用外部网页资源。
本地服务只监听 `127.0.0.1`，不能从局域网其他电脑访问；网页会自动建立本机会话令牌，无需用户配置。

## 二、每天采集

1. 在采集页面点击“读取 / 刷新类目和榜单”。
2. 如果程序新开了一个调试版 Edge，它会先打开与“商机中心”程序一致的抖店商机中心入口。请在这个页面手动登录并完成平台验证，无需自己寻找 TOP200 页面。
3. 回到采集页面，再点一次“读取 / 刷新类目和榜单”。
4. 在搜索框中查找并勾选一个或多个行业类目。
5. 品牌类型选择“不限、知名品牌、非知名品牌”中的一个。
6. 勾选一个或多个榜单后点击“开始采集”。
7. 等待状态变成“completed”，然后在历史任务中下载 Excel 或 JSON。

历史任务使用“日期时间｜榜单｜类目数量”的可读名称；鼠标停留在名称上仍可查看内部任务编号。页面显示最近 10 个已完成任务，并始终保留所有待处理、运行中、已停止和失败任务，磁盘上的旧报告不会被自动删除。

支持的榜单为页面前六个：

- 总榜
- 搜索榜
- 直播榜
- 商品卡榜
- 达人带货榜
- 短视频榜

按用户确认，不采集“实时爆品挖掘榜、退后购买榜、同行低退榜”。

## 三、采集口径

- 每个“行业类目 × 榜单”只检查平台原始排名前 200 名。
- 只保存红色上升箭头和“首次上榜”的商品。
- 有“实时”时使用实时；没有实时时自动使用“近1天”。
- 保存商品名称、价格带、商品链接、店铺名称和页面可见业务指标。
- Excel 明细中的“当前排名”是平台原始 TOP200 名次，不会按筛选结果重新编号。
- Excel 的“商品链接”列为可点击超链接。
- 店铺入口是二维码，按用户确认不采集店铺链接。
- 不保存商品图片或图片地址。
- 页面不足 200 条时按实际条数结束，不用空值或重复数据补足。

## 四、暂停、停止和恢复

- “暂停”会在安全检查点暂停；点击“继续”恢复。
- “停止”后已经完成的组合和当前检查点仍保存在项目目录。
- 电脑或程序意外关闭后，重新启动，在历史任务中点击“续跑”。已完成组合不会重复执行。
- 单个组合失败不会阻止后续组合。任务结束后可点击“重试失败”。
- 页面卡顿或翻页校验失败时，程序会自动重新定位页面并有限重试；整组最多尝试 3 次，仍失败才进入失败记录。

## 五、输出文件

报告保存在 `reports` 文件夹，文件名包含时间和任务编号，不覆盖历史报告。

Excel 包含：

1. `任务汇总`
2. 每个已选榜单各自的明细表，例如 `总榜明细`、`搜索榜明细`
3. `失败记录`

每张榜单明细表顶部包含采集时间、品类、筛选条件和采集统计，第 6 行开始是商品明细。采集时间固定显示为 `YYYY-MM-DD HH:mm:ss（北京时间）`，不受电脑系统时区影响。Excel 不写入内部任务编号、实际周期和趋势类型；这些技术字段仍完整保留在 JSON 中。不同榜单的专属指标不会混入同一张表。

JSON 保留任务参数、统计、结果、动态字段和失败原因。运行中的任务与检查点保存在 `data` 文件夹。

## 六、复制到其他电脑

1. 退出正在运行的采集任务。
2. 整体复制 `Tiktok TOP200` 文件夹。
3. 新电脑安装 Node.js 20+ 和 Microsoft Edge。
4. 在新电脑上双击 `安装依赖.bat`，然后双击 `启动采集.bat`。

不要单独复制某个脚本，也不要复制或迁移 Edge Cookie、用户数据目录。

## 七、常见问题

### 找不到 Edge

页面会要求填写 `msedge.exe` 的完整路径。通常位于：

```text
C:\Program Files (x86)\Microsoft\Edge\Application\msedge.exe
```

### 提示未登录或找不到 TOP200 页面

请确认是在程序启动的调试版 Edge 商机中心页面中完成登录，然后重新读取类目和榜单；程序会自动进入 TOP200 页面。

### 页面一直加载或翻页失败

程序会先自动有限重试；仍失败时等待网络恢复，再在历史任务中重试失败组合。不要高频点击，不要刷新正在采集的 TOP200 页面。

### 某榜单使用近1天

这是正常行为。搜索榜、直播榜或达人带货榜等没有实时选项时，程序会按规则自动切到近1天，并在报告中记录实际周期。

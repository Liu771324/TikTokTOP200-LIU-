# 商品标题工作台

双击 `启动标题工作台.bat`，先在系统默认的普通浏览器打开 http://127.0.0.1:8080。表格可直接预览；尚未打开调试 Edge 时，点击右上角“连接 Edge”，再启动调试浏览器并进入抖店、小猪业务页面。已打开 9222 调试会话时自动检测并复用，工作台网页不会在调试会话中打开。

重复双击启动脚本时，若 8080 已运行本标题工作台，直接打开现有页面；不会重复启动服务或报告端口占用。8080 是工作台端口，9222 是 Edge 调试端口，分别检测。

需要 Node.js 20 或更高版本和 Microsoft Edge。迁移包不包含可下载的依赖；在其他电脑完整解压后先运行 `安装依赖.bat`，按锁定清单安装，再运行启动脚本。详细步骤见 `迁移说明.md`。

1. 尚未连接时点击“连接 Edge”。如果工作台显示等待登录，在调试 Edge 完成抖店和小猪的登录或验证，工作台自动继续。连接失败可点击“重新连接 Edge”。
2. 在左侧选择商品状态和本次店铺，在“标题预览”切换分组核对原标题和新标题，点击底部“开始修改标题”。商品状态默认“所有”，选项自动读取小猪页面；默认不选择任何店铺。开始后锁定商品状态与店铺，全部分组及保存结果核对均按本次状态查询，结果中显示所选状态。
3. 在“执行结果”查看逐件结果。点击“停止任务”后，不再保存后续商品；正在提交的商品会先核对结果。
4. 点击“下载失败 Excel”取得失败商品清单，包含商品 ID、店铺名、失败原因、新旧标题及表格行号；商品 ID 按文本保存。失败清单自动保存到 `reports` 中本次任务的 `-失败商品.xlsx`。原有“下载结果”仍提供完整 JSON 明细。

自动识别同目录 `标题.xls` 或 `标题.xlsx`，只读取其中的 `Sheet1`：A1 是“原标题”，B1 是“新标题”。两份同时存在时会提示，请只保留本次需要处理的一份文件；工作台会显示实际读取的文件名。A 列空白沿用上一原标题，B 列空白跳过。标题正文不截断、不改写，输入工作簿不覆盖。每次开始会重新读取文件，修改文件后可点击“重新读取”核对。

每组按页面查询结果的显示顺序，跨店铺连续分配新标题；商品或标题多出的部分保留或记录未使用。每件通过平台行内保存，读取平台 60 上限计数。明确保存失败时最多重试一次；仍失败则记录该件并跳过，继续下一件商品和下一条新标题，失败的标题不重新分配。标题超限、平台改写标题等已确认未保存的单件问题同样跳过。响应不确定时重新查询核对，无法确认则停止。已成功修改的数据不回滚。

关闭最初启动服务的窗口、点击“退出工作台”或关闭已连接的调试版 Edge 都会停止任务并释放 8080。退出工作台也会关闭同一调试会话的 Edge，普通浏览器会话不会被关闭。调试会话中其他标签页也属于该会话，请在退出前保存需要保留的内容。仅当 8080 被其他程序占用时启动失败，不自动更换端口。

登录验证、授权失效、查询失败或无法核对保存结果时，仍按工作台的停止位置处理原因后重新开始。任务不会自动恢复，也不会自动回滚；结果未知的商品会在 Excel 中标记“结果待核对”，应先人工核对。

开发验证：仓库源码包含测试，可运行 `npm test`；迁移包只包含运行所需文件。实际平台保存验证与自动测试分开记录，自动测试不会修改真实商品。

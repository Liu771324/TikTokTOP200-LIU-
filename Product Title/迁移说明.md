# 在其他电脑使用商品标题工作台

1. 在 Windows 电脑安装 Node.js 20 或更高版本和 Microsoft Edge。可从 [Node.js 官网](https://nodejs.org/)及 [Microsoft Edge 官网](https://www.microsoft.com/edge/download)下载安装。
2. 将迁移 ZIP **完整解压**到一个普通文件夹，不要直接在压缩包里运行。支持中文路径；工作台不依赖本机原来的 D 盘目录。
3. 双击 `安装依赖.bat`。需要联网，按 `package-lock.json` 安装依赖；看到安装成功提示后关闭窗口。
4. 检查同目录的 `标题.xls` 或 `标题.xlsx`。迁移包附带打包时的当前标题表；可换成自己的文件，两种文件只保留一份。只读取 `Sheet1`，A1 为“原标题”，B1 为“新标题”。
5. 双击 `启动标题工作台.bat`，系统默认浏览器打开工作台。点击“连接 Edge”，在调试 Edge 中完成抖店和小猪登录，然后回到工作台选择店铺、核对标题并开始。

新电脑需要重新登录业务平台。迁移包不包含浏览器登录资料、Node.js / Edge 安装程序、`node_modules`、Git 历史、开发测试、历史任务报告或截图。第一次安装依赖需要联网；以后在同一文件夹启动，无需重复安装。

失败商品清单和完整结果会保存在新电脑的 `reports` 目录，也可从工作台下载。已有 8080 工作台服务时会复用；8080 被其他应用占用时，需要先关闭该应用。

## 从 Git 仓库复用

从仓库获取整个 `Product Title` 文件夹，保留 `public` 子目录和 `package-lock.json`，再按上面的步骤安装。业务标题表不提交到仓库，需要自己放入 `标题.xls` 或 `标题.xlsx`。

## 重新打包

双击 `打包工作台.bat`。ZIP 和校验文件生成在本项目的 `portable` 文件夹，已经加入 Git 排除清单，不会上传。打包使用明确的运行文件清单，只附带当前标题表，不包含依赖和历史报告；不会删除本机已有依赖。

# 商品最小净含量提取 · 复用操作说明

> 用法：下次把**新的商品明细表**和**这份说明**一起发给 AI，并说一句"按这份说明提取最小净含量"，AI 即可直接照此产出结果表，无需再重复确认规则。

---

## 一、任务目标

从商品明细表里，按 **商品ID** 汇总其下所有 SKU 的克重，找出每个商品ID的**最小净含量**，并把净含量相同的商品ID归到一起，输出结果表。

## 二、输入表要求

- 输入为一张商品 SKU 明细表（`.xls/.xlsx/.csv` 均可，扩展名是 .xls 但实为 xlsx 也能读），每行是一个 SKU。
- 必须包含的列（列名允许有细微差异，按语义识别）：

| 列名 | 含义 | 是否使用 |
|---|---|---|
| 商品ID | 商品唯一编号（19 位长数字，**必须按文本处理**，禁止变成科学计数法） | 分组主键 |
| 商品标题 | 商品名称 | 仅"无克重"表附带 |
| SKU编码 | 规格编码 | 不参与计算，可作交叉核对 |
| **SKU名称** | 如"海苔碎100g*1袋\|亲民实惠" | **净含量只从这一列提取** |

- 同一个商品ID通常对应多行（多个 SKU名称）。

## 三、提取规则（核心）

### 1. 哪些算"重量"，怎么取值

| 写法 | 处理方式 | 示例 |
|---|---|---|
| 数字+**g** | 计为克重；g 后可直接跟中文（如"200g莲子"），正则不能用 `\b`，用 `(\d+(?:\.\d+)?)\s*[gG](?![a-zA-Z])` | 100g、3.5g |
| 数字+中文**克** | **等同 g**（250克=250g）；正则 `(\d+(?:\.\d+)?)\s*克`（自动排除"千克"） | 芡实250克 |
| 数字+**kg** | **仅当商品按重量卖时 ×1000 换算成克**（1.3kg=1300g、1kg=1000g）。**例外：商品主要按"块/枚/个/只/粒/片"等个数卖时，夹带的整箱 kg 装不换算**，进无克重表 | 燕麦片1kg→1000g；月饼按块卖+5kg整箱→无克重 |
| 数字+**ml/毫升** | 体积，**不换算成克**；商品没有克重、只有 ml 时进【总表】，净含量写"数字+ml" | 小磨香油420ml |
| 数字+**斤/半斤/一斤** | **一律不换算**；商品只有斤、没有 g/克/kg 时 → 进【无克重】表 | 拇指玉米1斤、各半斤 |

### 2. 一律不计入重量的内容

- **数量单位**：`袋/罐/盒/包/片/个/瓶/件/支/枚/粒/根/条/朵/块/桶/箱/小罐/大罐` 等前面的数字是件数，不计。
  - "韭菜籽枸杞5g*10包" → 只有 **5g**，10包不计；"罗汉果5个" → 无克重。
- **尺寸**：`cm/mm/厘米` 及尺寸区间（如"0.8-1cm""1-1.5cm"）是大小不是重量，忽略。
- **错填固定标签 1g / 1克**：凡提取到的 **1g、1克一律丢弃**（源数据"红枸杞1g*1罐|…""…|1克"这类固定错标签，不是真实规格）。
- **g 与数字写反**：形如"绞股蓝g*250罐"（g 在数字前）**不做还原修复**；该商品若没有其它正常克重，进【无克重】表。
- **包赔/补偿克数条款（最高优先，整商品入无克重）**：形如"酸甜角【150g+**赠50克抵扣坏果**】200g"、"X克包赔/缺重补偿/赔付"，其中紧跟"抵扣坏果/包赔/缺重/补偿/赔付"的克数是售后补偿、不是规格；一旦出现这种拿不准的补偿克数，**不强行剔除取值，整个商品直接进【无克重】表**（用户拍板：不确定的进无克重，不猜）。注意"送刮刀/送杯勺"等不带重量的赠品不影响、正常取 g。

### 3. 取值与分组

1. **组合装**把里面每个重量都纳入再取最小："丹参100g+橘皮80g+山楂80g" → {100,80,80} → **80g**。
2. **同一商品ID取最小**：该商品下所有有效重量的最小值即净含量。
   - 海苔碎含 100g、250g → **100g**；沙拉酱含 280g、1.3kg(=1300g) → **280g**。
3. 同时含 g 和斤的，按 g 取值、**忽略斤**（如红薯淀粉有250g又有3斤 → 250g）。
4. **个数售卖优先**：商品没有 g/克、SKU 主要按"块/枚/个/只/粒/片/根/条/支"等离散个数卖时，即使夹带 5kg、X斤 这类整箱/散装大规格也**不换算**，整商品进【无克重】表（判别：罐/袋/瓶/盒/件/桶/箱是包装单位，不算离散个数；块/枚/个等才算）。
   - 广式小月饼：28 个 SKU 按 10~100 块卖 + 1 个"5kg*1件"整箱 → 按块卖，进无克重，**不是 5000g**。
   - 反例：燕麦片只有"1kg*1罐/2kg*1罐"、无个数规格 → 属按重量卖，换算为 **1000g**。
5. 真实小规格要保留：茶包"3g*10包"、棒棒糖"4g*1根"的 3g/4g 是单包/单根净含量，属正常值。

## 四、输出规范

输出一个工作簿，包含**两张子表**：

### 子表 1：`净含量汇总`（主表）

- 两列，表头逐字命名：**商品ID | 净含量**。
- **净含量写法**：克重为"数值+g"（如 `50g`，整数不带小数、不写"克"）；毫升为"数值+ml"（如 `420ml`）。
- **排序与分组**：先把所有 **g 按数值升序**排列，相同净含量相邻；**ml 条目排在 g 之后**、同样按数值升序。
- **商品ID 强制文本格式**，19 位完整、不变成科学计数法。
- 冻结首行，表头加粗、浅色底。

### 子表 2：`无克重`（单独列出，不混进主表）

- 进入条件（满足任一）：① 只有斤/半斤、按要求不换算；② 只有"g*数字"写反、无正常克重；③ 只按个/包/片/块/件或配料组合计、无任何重量；④ 青盐这类完全没标重量。
- 三列：**商品ID | 商品标题 | 情况说明**；"情况说明"写明原因并保留原始 SKU 规格，便于人工判断。
- 注意：**只有 ml 的商品不进此表，而是进主表**（净含量带 ml）。

## 五、交付前校验清单（逐项核对后再交付）

1. **守恒**：主表行数 + 无克重表行数 = 输入表去重后的商品ID 总数，一个不多一个不少。
2. 抽查至少 3 个商品（含首行、中间、末行），人工比对 SKU名称确认最小值取对。
3. 确认所有 1g/1克 已排除；红枸杞类取真实最小值而非 1。
4. 确认中文"克"已等同 g、kg 已 ×1000；斤未被换算（仅斤商品在无克重表）；g*数字写反商品在无克重表。
5. 确认 ml 商品在主表且带 ml 后缀、排在 g 之后；主表 g 升序、同值相邻。
6. 确认数量单位、cm 尺寸未被误当重量；商品ID 全部为文本、19 位无失真。
7. 默认交付**在线表格链接**（如飞书表格）；用户明确要本地文件时交付 `.xlsx`。多份输入表分别产出各自的结果工作簿。

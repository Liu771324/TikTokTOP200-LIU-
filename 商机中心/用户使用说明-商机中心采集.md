# 抖店商机中心多类目采集：用户使用说明

## 1. 功能

工具连接已经登录的调试版 Microsoft Edge，从真实商机中心读取类目。你可以搜索并同时勾选多个类目，程序会按勾选顺序串行采集，最后生成一份合并的 Markdown、JSON 和 Excel 报告。最终增长商品会按全任务重复核心词自动分组。

多类目任务支持暂停、停止、继续和只重试失败类目。完成一个类目后会立即保存检查点；服务重启或手动停止后，继续任务不会重复已经完成的类目。

## 2. 第一次使用

1. 安装 Node.js 20 或更新版本。
2. 双击 `安装依赖.bat`，等待安装完成。
3. 以后换电脑时复制整个项目文件夹，在新电脑重新执行一次安装依赖即可。

## 3. 每天采集

1. 双击 `启动采集.bat`。
2. 打开 `http://localhost:8080`。
3. 点击“读取 / 刷新类目”。
4. 如果调试版 Edge 要求登录，在该 Edge 中完成抖店登录，再回到本地页面点击“我已登录，继续”。
5. 在类目搜索框输入关键词，勾选一个或多个类目。
6. 填写最低金额；最高金额可以留空。
7. 如需减少详情读取，可勾选“仅提取近30天增长商品（仅红色向上箭头）”。默认不勾选；勾选后绿色向下、持平或无法确认方向的商品不会打开详情。
8. 点击“创建批量任务并开始”。
9. 等待所有类目完成后，在当前任务或任务记录中打开报告。

不要关闭启动采集的命令行窗口，不要在采集中手动刷新或操作商机中心页面。

## 4. 金额区间

平台显示的是金额档位，不是精确金额。只有整个档位完整落入填写区间才会采集。

例如设置 `1万—25万`：

- `25万-50万`：跳过。
- `10万-25万`：采集。
- `7500-1万`：停止继续向后扫描。

最高金额留空表示不限制上限。

## 5. 任务控制

- “暂停”：在安全边界等待，当前任务和检查点保留。
- “继续”：恢复当前暂停任务；历史未完成任务也可以继续。
- “停止并生成部分报告”：完成当前商品后停止，生成独立部分报告。
- “重试失败”：只重新执行失败类目，已完成类目不重复。

## 6. 报告

完整任务使用：

- `选品报告-成交增长.md`
- `选品报告-成交增长.xlsx`

停止或存在未完成类目时使用：

- `选品报告-成交增长-部分.md`
- `选品报告-成交增长-部分.xlsx`

历史 Markdown 和 JSON 位于 `reports/`。部分报告不会覆盖上一份完整报告。

Excel 包含三个工作表：

1. `采集汇总`：任务状态、类目进度和分类统计。
2. `成交增长`：全部类目合并明细，列顺序为“#、产品分组、类目、产品名称、近30天总成交、昨日成交、今日成交、较昨日增长”；连续相同的已识别产品分组会合并单元格。
3. `失败记录`：类目、页码、商品、阶段、原因和重试次数。

Markdown 会逐行重复显示产品分组。产地、加工属性和包装词不会作为产品分组；剔除这些词后只剩两个明确商品字的单条商品也可独立成组。仍无法可靠识别核心词的商品显示“未归类”，不同未归类商品不会合并。报告汇总同时记录预筛选模式、通过数、跳过数和实际打开详情数。

## 7. 安全说明

- 只连接真实 Edge 的 `9222` 调试会话。
- 不复制、导入或解密 Cookie。
- 不并发启动多个 Edge 采集进程。
- 验证码和登录操作由用户本人完成。

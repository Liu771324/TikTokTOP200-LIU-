销量读取和销量阶梯、特定渠道补充技术服务费、达人佣金、广告费、税费、抖店开放平台自动同步和聚水潭正式 API 同步均不属于本次 V2 范围。

## V2 使用流程

```text
导入聚水潭成本
→ 上传带类目的抖店商品表
→ 导入官方基础服务费目录并核对经营大类识别
→ 配置可复用运费模板并绑定商品ID
→ 按需设置特殊地区价格
→ 在插件查看成本拆解
```

## 后续条件

聚水潭正式 API、在线成本同步和代码签名属于 V2 之外的后续条件。至少 10 条真实最低到手价对照仍作为后续数据抽查，不是本次构建已完成的验证项。API 条件具备后，还需要另行完成正式权限、令牌、全量同步、数量核对和 API 数据抽查。

## V1 使用口径

- 成本来源只使用同一日期的普通商品表和组合商品表。
- 映射只接受抖店商家 SKU 编码与聚水潭编码逐字符相等的记录。
- 未匹配、成本缺失或成本为零时不展示看似有效的涨跌率。
- Edge 扩展只读取抖店页面并查询本机数据。
- 当前 V2 正式包固定七个桌面页面，开发用途的人工核验资源不进入交付包。

# 商机双链路控制台

## 启动

推荐直接双击：

```text
启动界面.cmd
```

浏览器打开 `http://127.0.0.1:4173`。

## 使用

1. 页面未连接 Edge 时，点击“启动共用调试 Edge”。它与“商机中心”项目共同使用端口 `9222` 和 `%TEMP%\edge-debug` 用户目录。
2. 在打开的 Edge 中登录商机中心。开始采集时，程序会按照 TOP200 项目的流程，通过同一个调试会话自动创建或复用罗盘“本店搜索词”页面；如果仍被重定向，会返回商机中心并提示重新登录。
3. 上传 `.xlsx` 选品表格，表格中需要有“热门搜索词”或“搜索词”列。
4. 确认页面显示“Edge 已连接”和“选品表格已就绪”。
5. 点击“开始双链路采集”。
6. 任务完成后点击“下载采集结果”。

结果仍输出到项目的 `outputs` 目录，不覆盖历史文件。

## 表格要求

- 仅支持 `.xlsx`，文件不超过 25 MB。
- 任一工作表中需要有“热门搜索词”或“搜索词”表头。
- 系统按表格顺序读取、自动忽略空白项，并合并完全相同的词。

## 登录链路

系统不直接打开罗盘登录页。它按照 TOP200 项目的已验证方式，先确认共用调试版 Edge 中存在已登录的商机中心，再在同一浏览器上下文创建或复用罗盘“本店搜索词”页面。共用配置固定为：

```text
调试端口：9222
用户目录：%TEMP%\edge-debug
```

## 常见问题

- 显示“Edge 未连接”：点击“启动共用调试 Edge”，在打开的商机中心完成登录后重试。
- 罗盘被重定向：回到商机中心确认登录仍有效，再开始任务。
- “未处理记录”有数据：通常表示罗盘筛选后没有匹配词，或当前商品类目无法联动；主结果仍会正常导出。
- 页面只显示简短错误：完整的第三方运行时源码会被过滤，避免乱码和超长日志；可读原因会写入任务日志与“未处理记录”。
- 采集翻页默认约 2.5 秒一次；这是为降低抖店“系统繁忙”概率设置的安全节奏，请不要同时手动操作采集页面。
- 罗盘类目、查询接口或结果区短暂未加载时会自动重载并重试，最多 3 次；商机分页无法确认时会丢弃该轮半截数据并从第 1 页重采。
- 商品类目只从标题包含当前核心词的商机卡片读取；页面最前面的无关卡片会被跳过。
- 结果 Excel 使用深蓝与橙色运营风格，显示记录数和生成时间，并提供筛选、冻结表头、核心词分组线和重点数据高亮。

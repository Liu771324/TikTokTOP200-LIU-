## 已确认原因

`compass-page.js` 的 `identity()` 将封面规范化为 `origin + pathname`，随后 `captureItems()` 又把这个去重用地址作为 `details.coverUrl` 返回。罗盘图片 CDN 的签名查询参数因此丢失。实际数据库中的封面地址没有查询参数，少量只读请求确认返回 HTTP 403；添加罗盘 Referer 后仍是 403。

这与单纯的网络慢或图片占位布局无关。旧记录丢失的签名无法从数据库还原，必须重新读取原页面；不能猜签名或借用其他视频的封面。

## 实施步骤

### 1. 分离视频身份和图片地址

- `cover` 保持原规范化值，仅用于卡片哈希、去重与页面身份匹配。
- 单独保留页面实际图片地址 `coverUrl`，包括图片服务器要求的查询参数，只作为展示元数据返回。
- 宿主既有 HTTPS、平台图片域名及长度白名单继续生效；签名不进入 sourceKey、locator 或公开视频链接。
- 前端图片失败说明“封面已失效，请重新读取当前页”，区分没有封面的旧记录。签名图片本身可能到期，重新读取可更新地址；本轮不增加视频预览文件或图片备份。
- 修改既有回归断言，使其区分展示地址与稳定身份；本轮不新增或运行测试套件，使用故障定位、源码检查及构建校验记录证据。真实页面只有用户保持页面打开后才核对。

### 2. 应用用户图标和名称

- 输入：`D:\浏览器下载\小叶电商工具箱图标设计.png`，2048×2048 RGBA，已确认有透明通道。
- 仅裁去透明外边距、等比缩放并生成 PNG/多尺寸 ICO，不修改设计；资源随源码和发布白名单管理。
- PNG 用于侧栏、favicon 和托盘；ICO 用于桌面窗口、EXE 与安装器。
- 安装 AppId、EXE 文件名、单实例互斥量和数据目录不改。升级时清理本产品旧名称快捷方式，创建新名称，避免重复入口。

### 3. 交付和留档

- 中等范围：修改路径自查一次；构建执行现有资源白名单校验，检查版本、图标资源与安装结果；不重复运行成本模块验收。

# 默认导出位置

内部任务、视频资产和浏览器资料仍归工具箱数据目录管理；用户选择的下载文件夹只作为默认导出位置，不影响内部统一去重。

- 存储管理新增“默认导出位置”和“选择文件夹”，只通过系统目录对话框选择，不接受界面输入任意路径。
- `storage.get_export_location({})`返回`{path: string|null}`；`storage.choose_export_location({})`取消返回`{cancelled:true}`，成功返回`{path, cancelled:false}`。
- 选中目录使用现有外部路径校验，拒绝内部数据目录及其子目录。设置以`{version:1,exportDirectory:string}`原子存于当前数据根的`preferences.json`，随数据目录迁移保留。
- 已设置时视频点击导出直接写默认目录，沿用任务/商品归类、MP4与文案TXT成对、重名避让及原有文件保护；未设置时仍每次选择文件夹。
- 单份报告和待选列表Excel仍使用系统保存对话框，只把初始directory设为默认导出目录。保存取消、占用、失败语义不变。
- 下载完成不会自动复制到导出目录，不产生额外备份。设置变更不会搬动已有导出文件。

验收：设置持久化与取消、内部路径拒绝、视频无二次选框/成对导出及重名避让、报告与待选Excel保存初始目录、原文件防护回归；存储界面显示与空参数调用冒烟检查。

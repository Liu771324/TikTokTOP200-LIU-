## 范围与停止点

沿用[整改方案](TOOLBOX_COST_INTEGRATION_PLAN.md)的业务修复部分，开发对象为 `Cost Accounting(成本价）` 独立程序。保持表格 → 后台预览 → 确认、备份和发布 → 本机只读 HTTP → Edge 扩展的数据流。工具箱入口、worker、安装器、数据迁移不在本阶段实施。

完成范围：独立版数据发布保护、通用表格导入向导、运费/费率界面修正和扩展重连，以及操作和实际覆盖说明。现有业务库、表格、备份和安装数据保持原位；需要真实数据操作时另行落实明确源目标及用户授权。

地区沿用精确文本规则并清楚标注，先不自行转换省市或配置特殊地区金额。金额沿用 Decimal 原始计算和既有显示口径。通用导入首批 XLSX/CSV/TSV；旧 XLS 未经受限读取验证不开放。

## 核对方式与预算

范围按大改动管理。每个阶段核对受影响数据流和异常分支一次，最终集中审阅；初始源码核对和语法检查预算约 30 分钟。用户随后明确授权临时空库/合成表格针对性验收，增加一次分层隔离验收；实际审阅发现的提交标记持久化和扩展重连遗漏各补一项回归，不重复全仓审计。

实施前阅读相关现有测试以保持兼容；语法、审阅、隔离运行和真实页面验证分开记录。所有本轮运行测试仅使用临时合成资料，没有启动正式成本服务或读取真实业务库。

- 运费草稿与保存后共用 Decimal；0.8/0.7/0.1 不多计续重档，空重量显式首重估算，新增地区空值不猜为零。修改/绑定显示影响和旧→新；停用模板禁止新增绑定；每页 100，翻页/筛选清勾选。
- 费率当前/历史/未来视图、可覆盖非实际命中说明、末尾缺失类目的父级覆盖统计、上海日期一致。既有币种、舍入及精确地区语义未扩展。
- 服务健康不扫描全库，统计按修订刷新；同批只读快照，发布和查询统一管理锁；启动/修订身份用于扩展连接与旧响应阻断。扩展首次人工核对连接，同目录重启自动重连，错库/协议/来源拒绝/通信异常分类；保存和刷新失败分开处理。

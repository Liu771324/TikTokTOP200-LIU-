## 实施契约

1. 核心迁至 `toolbox/engines/cost`；成本测试、文档、扩展分别迁至 `toolbox/tests/cost`、`docs/cost`、`toolbox/browser-extension/cost`。先复制、验收后删除旧目录。
2. 宿主通过持久隐藏 `--cost-service-worker` 管理成本服务；同一共享冻结 exe 承载，成本业务库独立置于统一数据根的 `cost`。退出等待写入完成，不采用采集 worker 的强杀超时；读取失败不重放写入。端口冲突明确提示，禁止接管未知服务。
3. 主窗口 `cost.*` 动作白名单经可信桥接进入 worker。文件只由宿主选择并复制至受控输入目录，界面传文件 ID，IPC 不传整表 Base64。输入和响应均有界。管理接口不开放到 HTTP。
4. 复用七个正式页面，通过 Shadow DOM 隔离样式与查询作用域；主工具列表仅一个成本入口。保留表单状态，离开时停止轮询、回来恢复，隐藏页面不触发新提交。人工核验开发页不进入正式包。
5. 首次启用创建空成本库；已启用后随工具箱启动。开发版实际资料在停服后复制：完整哈希、SQLite 完整性、表行数及备份引用核验后切换；迁移前原件保留在本地归档。后续数据位置迁移包括整个 `cost` 目录。
6. 存储管理单列成本库、备份、日志、临时输入。任务/视频/通用缓存清理不处理成本文件。更改数据位置与成本写入互斥；关闭后释放成本服务再迁移。
7. 冻结包只收源码编译产物、静态资源、公开费率及扩展文件，不包含业务种子、开发资料和数据库。保留既有基础代码保护；更新安装版到统一目录。

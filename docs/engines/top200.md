# TOP200 引擎交接规则

2026-10-14 从旧 TOP200 完整交接文档、抖店环境约束和现有实现提取。业务模块位于 `toolbox/engines/top200`，由 `toolbox/node/adapters/top200.cjs` 注入受管浏览器、检查点和报告登记。

- 先扫描平台原始前 200 名，再过滤上升与首次上榜；当前排名保留原始名次，不能给过滤结果重编号或补足 200 条。
- 前六个业务榜单参与采集，三个特殊榜单排除。实时优先，否则近1天；品牌条件单选。切换榜单可能重置类目，因此必须先切榜、再设置并校验完整行业路径。
- 周期控件兼容旧 radio 与新 tab；周期和榜单具有不同控件组，不能全局读取全部 tab。以激活标签及表格判断当前榜单，不能仅凭页面标题。
- 表格稳定后读取；固定列与横向滚动 DOM 可能重复。翻页同时检查页码与商品指纹，最多三次；整组失败从第1页有限重试三次，失败尝试的局部结果不混入正式结果。不得刷新采集中的页面或无限重试。
- 商品链接必采；Excel 保存可点击超链接，店铺只记名称。组合内优先按规范化商品链接去重，保留 origin、pathname 和商品 id；无链接时按商品名与店铺名。不同类目/榜单不合并。
- 保留平台金额、点击量、件数区间原文。字段按榜单及表头语义映射，不能只按列序号或把相似字段跨榜覆盖；无法识别的业务字段进入动态字段，操作列与二维码不进入数据。
- 报告按榜单分表，JSON 与 Excel 明细总数一致，失败保留阶段、页码、原因及重试次数。组合失败时不能仅凭旧状态 `completed` 宣称数据完整。
- 暂停/停止在安全边界落盘，恢复跳过已完成组合；失败重试仅重跑失败组合并去除它们的旧结果。工具箱统一管理状态和输出，旧 task-store 的独立入口仅作为兼容模块，不是发布入口。
- 真实 Edge 登录由用户完成；受管 CDP 会话由宿主授予，禁止复制用户浏览器资料、导入 Cookie 或绕过验证。页面改版时先取脱敏 DOM 与可复现行为，再修改选择器。

现有业务测试迁入 `toolbox/tests/engines/top200`；旧网页、HTTP服务、Windows启动脚本专项测试随独立入口删除。task-store/export 测试在临时目录内执行，不写引擎源码目录。

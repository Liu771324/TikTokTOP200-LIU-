# 成本助手（工具箱）

从电商工具箱左侧“成本助手”进入。内部页签依次为运行概览、成本导入与更新、抖店商品对应关系、基础服务费、运费模板、更新历史、运行日志。

## 使用流程

1. 选择 XLSX/CSV/TSV 通用成本表，或聚水潭普通表与组合表。通用向导可选择工作表、表头行和对应列，保留文本 SKU 与前导零，不按名称猜测编码。
2. 确认来源与当前目录使用同一套 SKU，金额为人民币单个销售 SKU 的基础商品成本。增量更新保留未出现商品；全量替换必须确认完整目录范围。
3. 先看新增、修改、移除和错误预览，再确认。成本、映射、运费和费率更新均有备份与统一历史；断线后先查历史，避免重复提交。
4. 导入店铺商品对应关系后，维护基础服务费和运费模板。缺失组件分别显示，不按零计算；扩展始终只读，不执行抖店报名、改价或提交。

## 浏览器与后台

上方“浏览器扩展设置”提供扩展目录和 Edge 扩展管理入口。首次使用需开启开发人员模式并加载目录；已经加载时重新加载。数据迁移后须在扩展中重新核对、配对数据源。扩展固定 ID 沿用独立版。

成本服务由工具箱的共享冻结程序管理，端口 8765。启用后随工具箱启动，切换工具或关闭到托盘继续服务；退出会等待资料操作结束。若端口被原独立版占用，退出原程序后重试。只读查询可重连，管理写入不会自动重放。

## 文件位置

- 共享核心：`toolbox/engines/cost`；正式七页：`toolbox/web/cost`；扩展：`toolbox/browser-extension/cost`。
- 成本资料在工具箱当前数据根的 `cost` 内。本机为 `D:/前端/ai/电商工具箱/数据/cost`，程序为同级 `程序` 目录。
- 独立安装包 0.2.0、迁移前资料、原始来源表和旧恢复副本在本机 `local-archive/legacy-tools/cost-assistant-0.2.0`；原 `Cost Accounting(成本价）` 开发目录已在验收后删除。
- 存储管理单列成本库、有效备份、日志和临时输入。普通任务及缓存清理不删除成本业务资料；更改工具箱数据位置包含整个成本目录。

## 开发与验证

核心回归：在总仓运行 `python -m unittest discover -s toolbox/tests/cost -q`；宿主接入：`python -m unittest toolbox.tests.test_cost_integration -v`；页面：`python -m toolbox.tests.cost_ui`。使用隔离数据，Windows 回环/桌面测试需允许本机连接；临时目录设在项目 D 盘，不使用正式成本库。

八页开发资源和人工核验后端保留在 `toolbox/engines/cost/webview_static` 等核心模块中，正式安装包不包含人工核验入口。未开放旧 XLS、通用 BOM、模糊匹配、其他币种或多来源自动定价。
